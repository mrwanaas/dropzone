🔥 Firebase — Synchronisation Multi-Appareils
Pourquoi Firebase ?
Sans Firebase, les produits et commandes ne sont visibles que sur un seul appareil. Avec Firebase (gratuit), tout se synchronise en temps réel sur tous vos appareils.

Configuration en 5 étapes :
1. Allez sur console.firebase.google.com et créez un projet (gratuit)
2. Dans le projet : Realtime Database → Créer une base de données → choisir Mode test
3. Allez dans Paramètres du projet → Vos applications → ajouter une application Web (</>)
4. Copiez tout le contenu de firebaseConfig = { ... }
5. Collez-le ci-dessous et cliquez Connecter
